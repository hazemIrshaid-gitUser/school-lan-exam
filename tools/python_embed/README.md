# بايثون المحمول (Windows embeddable)

الحزمة الكاملة (الزيب) بتجي ومعها مجلد `python` جنب `server.py`، وملفات التشغيل (`start.bat` و`check_files.bat` و`report_problem.bat`)
بتستعمله أول شي، فالمشرف **ما بيحتاج يثبّت بايثون**. لو المجلد مش موجود بتستعمل بايثون النظام (`python` ثم `py`).

- النسخة: **Python 3.14.8** (64 بت)، مدعومة أمنياً (صدرت 30-9-2026). المصدر الرسمي: https://www.python.org/ftp/python/3.14.8/python-3.14.8-embed-amd64.zip
- الحجم: 12601679 بايت
- SHA-256 (مطابق للمنشور بصفحة https://www.python.org/downloads/release/python-3148/): `a93abe456ab01bd96d7a085b3cdb6566b3063f4241360d114142fbdb07f0a310`
- MD5 (محسوب محلياً): `2061ad3de181442b00795c61eaedf09f`
- التوقيع: ملفات `python.exe` و`python314.dll` موقّعة (Python Software Foundation، Authenticode صالح).
- الترخيص: PSF (الملف `python/LICENSE.txt` داخل المجلد).
- **ويندوز 10 أو أحدث فقط** (64 بت). حسب وثائق بايثون: ويندوز 8.1 بده 3.12، وويندوز 7 بده 3.8 (بتثبّته على الجهاز وبتحذف مجلد `python`).
- النسخة السابقة كانت 3.10.6 (منتهية الدعم): استُبدلت لهالسبب. نسخة 3.15.0 صدرت بـ 9-10-2026 وما اعتمدناها لأنها جديدة جداً.

## الملفات (مش بالمخزن لأنها ثنائية وكبيرة)
- `tools/python_embed/python-3.14.8-embed-amd64.zip`: الملف الأصلي (مستثنى من git).
- `1_الحزمة_الكاملة_لأستاذ_جديد/python/`: ناتج الفكّ (مستثنى من git). `build_zips.py` بيتأكد إن محتواه مطابق للزيب قبل ما يضيفه للحزمة.
- للفك من جديد: فُك الزيب داخل مجلد `python` كما هو (بدون تعديل أي ملف).

## فحص الاختبارات على نسخة بايثون ثانية
- `EXAM_PYTHON=<مسار python.exe>` قبل `pytest`: السيرفر (`test_http.Server`) وسيرفر وضع الكونسول بيشتغلوا بهالمفسّر بدل مفسّر pytest.
- لتشغيل pytest نفسه على المفسّر الجديد: انسخ المجلد لمكان مؤقت وأضف مسار site-packages لبايثون النظام بملف `python314._pth` (مكتبات pure/abi3 بتشتغل؛ Playwright لأ لأن greenlet مبني لنسخة النظام).

# نظام الامتحان الإلكتروني (شبكة المختبر، بدون إنترنت)

حزمة امتحانات إلكترونية للمدرسة: جهاز المشرف في المختبر بيشغّل سيرفر صغير، والطلاب بيفتحوا رابط من جوالاتهم أو أجهزتهم وبيحلّوا، والمعلم بيتابع كل شي مباشرة. **السيرفر بيشتغل بمكتبات بايثون الأساسية فقط** (بدون تنزيل أي شي)، وكل بيانات الامتحان بتضل على جهاز المشرف.

## توزيع الأدوار

| مين | شو بيعمل |
|---|---|
| **الأستاذ** | بيكتب أسئلته على قالب Excel (`questions_template.xlsx`) وبيعطي المشرف الملف والصور، وبيحكيله طلباته (المدة، عدد الأسئلة، العلامات). |
| **المشرف** | عنده جهاز السيرفر وقائمة الطلاب، بيضع ملفات الأستاذ، وبيشغّل الامتحان ويراقبه (`start.bat`). |
| **الطالب** | بيفتح الرابط، وبيختار اسمه، وبيحل سؤال بكل صفحة، وبيسلّم. |

## الميزات

- **ورقة مختلفة لكل طالب:** سحب عشوائي حسب المستوى (صعب/وسط/سهل)، وأسئلة ثابتة (عمود «ثابت») بتطلع بكل الأوراق، وخلط للأسئلة والخيارات.
- **التصحيح عند السيرفر:** الطالب بيستلم أسئلة ورقته فقط (بدون الإجابة الصحيحة ولا بنك الأسئلة)، فما بيقدر يشوفها من أدوات المتصفح.
- **واجهة الطالب:** سؤال بكل صفحة مع خريطة أسئلة، وكسور حقيقية (بسط فوق مقام)، وصور بالأسئلة والخيارات، ونافذة تأكيد قبل التسليم.
- **مراقبة حية:** من بدأ ومن سلّم والعلامات، تمديد الوقت، رسالة للطلاب، إنهاء الامتحان، «نقل لجهاز آخر»، «تسليم عنه».
- **صمود:** حفظ الإجابات على السيرفر أول بأول، وإذا وقف السيرفر أو نام الجهاز الوقت بيتعوّض تلقائياً، وحماية من نسيان «بداية امتحان جديد».
- **تقارير:** ملف Excel بعلامات الشعب وتحليل الأسئلة، وورقات الطلاب للطباعة، ومراجعة الأخطاء للطالب (اختيارية).
- **أدوات للمشرف:** فحص الملفات (`check_files.bat`)، وصفحة فحص السيرفر `/health`، وزر «جمع معلومات المشكلة» (`report_problem.bat`)، و«بروفة الضغط» (كل الأجهزة تضغط «ابدأ» بنفس اللحظة حسب ساعة السيرفر).

## محتويات المخزن

| المجلد | شو فيه |
|---|---|
| `1_الحزمة_الكاملة_لأستاذ_جديد/` | **الحزمة الكاملة**: `server.py` و`template.html` و`start.bat` والقوالب والأدلة (PDF). |
| `2_تحديث_لمن_عنده_النسخة_القديمة/` | لمن عنده نسخة قديمة: ينسخ `server.py` و`template.html` و`report_problem.*` وبيعيد تشغيل السيرفر (التفاصيل بـ `README_ar.txt`). |
| `3_للعرض_على_الأستاذة/` | صور شاشات للعرض (قديمة نسبياً). |
| `tests/` | الاختبارات الآلية (للمطوّر فقط). |
| `tools/` | `md_to_pdf.py`: بيولّد أدلة PDF من `_md_sources`. |

> الملفات `server.py` و`template.html` بمجلد `1_` و`2_` **لازم تضل متطابقة بالبايت.**

## تشغيل سريع (للمشرف)

1. ثبّت **Python 3** على جهاز السيرفر (ويندوز) وعند التثبيت علّم **Add Python to PATH**.
2. حط مجلد الحزمة خارج OneDrive (مثلاً `C:\exam`).
3. حط `questions.xlsx` (والصور بمجلد `images`) و`students.xlsx` بجانب `server.py`. ملف `settings.txt` اختياري.
4. شغّل `check_files.bat` (لازم يقول «الملفات سليمة»)، وبعدها `start.bat`.
5. افتح `http://localhost/monitor` للمراقبة، وأعطِ الطلاب الرابط اللي بيظهر بالنافذة السوداء.

التفاصيل الكاملة بـ `00_دليل_المشرف.pdf`، وورقة الأستاذ `03_ورقة_الأستاذ.pdf`، وقائمة فحص قبل الامتحان `02_قائمة_فحص_قبل_الامتحان.pdf`، وورقة الطوارئ `04_ورقة_الطوارئ.pdf`.

> صفحات المعلم (المراقبة، المفتاح، الورقات...) بتفتح من **جهاز السيرفر نفسه** على `localhost` فقط، وبعضها محمي بكلمة سر المعلم (`settings.txt`).

## الاختبارات

آخر فحص كامل: **796 ناجح، و1 متخطّى** (حوالي 28 دقيقة).

```bash
cd tests
python -m pip install pytest openpyxl playwright pypdf psutil pymupdf pillow markdown
python -X utf8 -m pytest -q -p no:cacheprovider
```

أو دبل كليك على `tests\run_tests.bat`.

- اختبارات المتصفح بتحتاج **Microsoft Edge**. وتجربة محرّك سفاري (آيفون): `python -m playwright install webkit` ثم `set EXAM_BROWSER=webkit`.
- اختبارات ملفات Excel الحقيقية بتحتاج Excel وLibreOffice (وبتنتخطّى بدونهم).
- الاختبارات بتشغّل السيرفر الحقيقي كعملية مستقلة، وبتضرب فيه فوضى عمداً (قتل، نوم، ملفات ممسوكة، 60 طالب مع بعض).

## ملاحظات للمطوّر

- **ملفات `.bat` لازم تضل بنهايات أسطر CRLF**، ومخزن git مضبوط (`.gitattributes` = `* -text`) على حفظ الملفات بالبايت بدون تحويل.
- `server.py` بيدوّر على نصوص معيّنة داخل `template.html` (`const CONFIG = {…};` و`const QUESTIONS = [\n];` و`const ROSTER = /*ROSTER*/{};` و`</script>\n</body>`...). لا تغيّرها، وإلا بيوقع السيرفر عند التشغيل.
- الأدلة بتنكتب بصيغة Markdown بمجلد `_md_sources`، وبتتحوّل لـ PDF بـ `tools/md_to_pdf.py` (بتحتاج Edge ومكتبة `markdown`). أوراق الطباعة (قائمة الفحص، ورقة الأستاذ، ورقة الطوارئ) لازم تضل **صفحة وحدة**، وفي اختبار بيتأكد.
- الملفات اللي بيعملها السيرفر وقت التشغيل (النتائج، الإجابات، الأوراق...) وملفات الأساتذة الحقيقية مستثناة من المخزن بـ `.gitignore`.
- رسائل الـ commit بالإنجليزي.

## حدود معروفة

- مجرَّب على **ويندوز 10 وبايثون 3.10** فقط.
- الرابط على الشبكة بدون HTTPS: المتصفح ما بيمنع قفل الشاشة تلقائياً (مثلاً بـ «بروفة الضغط»)، فمهلة الشاشة لازم تُضبط من إعدادات الجهاز.
- فحص سفاري بمحرّك WebKit على الكمبيوتر، مش على آيفون حقيقي.
- **مؤجّل:** تاب «إعدادات الامتحان» بصفحة المراقبة بدل تعديل `settings.txt` بالإيد.

## الإصدار

الإصدار الحالي مكتوب بأعلى `server.py` (`VERSION`).
